# Vulnerable Stand 2 Golang

Небольшой CTF-стенд на Go с веб-интерфейсом, статически зашитыми учетными данными и выдачей секретной строки после успешного входа.

## Запуск

Требования:

- Docker
- Docker Compose

Запуск стенда:

```bash
docker compose up --build -d
```

После запуска сервис будет доступен по адресу:

```text
http://127.0.0.1:5001/
```

Остановка стенда:

```bash
docker compose down
```

## Задание

1. Перейти на сервис по порту `5001`.
2. Найти логин и пароль, анализируя скачиваемый серверный бинарник.
3. Авторизоваться в веб-интерфейсе.
4. Получить секретную строку, которая читается из `flag.txt`.

## Подсказка

На главной странице есть ссылка `наш сервер`, которая отдает скомпилированный бинарник `server`. Его можно использовать для реверса и поиска учетных данных.
